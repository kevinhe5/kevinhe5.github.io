02 · THE STALE-WEIGHT MOMENT

The gradient is old.
The destination is current.

“Stale” does not mean PipeDream rewinds the model. It means the gradient was evaluated at an older point in parameter space.

THE SHORT ANSWER

W⁰ answers “how was this gradient computed?” W² answers “where should we apply it now?” Stashed weights are read-only context—not an update target.

Route deterministically

microbatch ID mod replica count picks the replica. No coordinator is needed for every handoff.

2

Return to the same GPU

A microbatch’s backward pass returns to the replica that ran its forward pass—and still has its activations and stashed weight.

3

Synchronize only that stage

Replica gradients go through a parameter server; fresh stage weights flow back. Pipeline neighbors exchange activations and input-gradients, not the whole model.

04 · TAKEAWAY

Consistent
doesn’t mean
current.

Weight stashing makes each microbatch’s forward and backward math consistent. It does not remove delay between gradient computation and application.

This explainer models the original 2018 PipeDream paper’s default semantics: 1F1B scheduling and weight stashing, without optional vertical synchronization.
